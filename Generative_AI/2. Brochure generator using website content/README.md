# Brochure generator using website content

## Description
This is a GenAI example to create brochure with website contents using locally running model or any non locally model been used. Non local model e.g. gpt-4o-mini requires api_key to use them.

## Prerequisites
- ENV file, if using non local models
- OpenAI setup
- Jupyter lab setup

## Details
On successful execution of this notebook, a brochure gets created using fetch website contents and from it's relevant links available inside it.
