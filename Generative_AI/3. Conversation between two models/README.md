# Conversation Between Two Models

## Description
This is a GenAI demonstration showcasing a conversation between two models:  
- **Model A** — consistently aggressive and argumentative, always disagreeing.  
- **Model B** — consistently polite, agreeable, and focused on keeping the conversation calm.  

## Prerequisites
- `.env` file (if using non-local models)
- OpenAI setup
- JupyterLab setup

## Details
When this notebook is executed successfully, the full conversation between the two chatbots will be displayed at the end of the run.  

In this example, local models are used via **Ollama** for installation and execution:  
- **qwen3** — highly argumentative, always taking an opposing stance.  
- **llama3.2** — calm, agreeable, and intent on continuing the conversation peacefully.  

## Business Relevance
This example demonstrates a structured conversational exchange stored as a list of messages.  
Such a format is fundamental in building conversational AI assistants, enabling them to maintain context and personality throughout an interaction.
