# Explain Code

## Description
This is a GenAI example to explain the code using locally running model or any non locally model been used. Non local model e.g. gpt-4o-mini requires api_key to use them.

## Prerequisites
- ENV file, if using non local models
- OpenAI setup
- Jupyter lab setup

## Details
On successful execution of this notebook, code explanation will gets displayed as a markdown output.
